# Align Sanity schema + queries to the seeded data

Goal: make the Sanity schema and GROQ queries match the field shapes in
`app/studio/scripts/seed/seed.ndjson`, so the content the user imports with
the Sanity CLI renders correctly in Studio and on the site.

Decisions (approved by the user in the session question panel):
- Align the schema to the seed data. Seed files stay untouched.
- The user runs the `sanity dataset import` and count verification on their
  machine; this prompt only covers the code alignment.

## Seed data (authoritative)

Inspected `app/studio/scripts/seed/seed.ndjson` (141 records: 120 lessons,
10 courses, 6 categories, 5 instructors).

Mismatches found vs current schema:
1. Lesson documents use `thumbnail` (an image with `alt`); the schema defines
   `poster`. Query projections reference `poster`.
2. Instructor `expertise` is an **array of strings**; schema defines a string.
3. Instructor `bio` is **Portable Text** (array of blocks); schema defines
   `text`.
4. Course `learningOutcomes[].icon` uses values not in the schema's option
   list: `gauge`, `sparkles`, `workflow`.
5. Images in seed carry `alt`; schema image fields do not define an `alt`
   field, but `imageFragment` already projects it.

Everything else already matches (modules, resources, notes, slug shape,
references, `videoUrl`, duration/price/studentCount, etc.).

## Files to touch

- `sanity/schemaTypes/documents/lesson.ts` — rename `poster` field to
  `thumbnail` (title "Thumbnail"), add `alt` to its image fields, update the
  document `preview` media selector to `thumbnail`.
- `sanity/schemaTypes/documents/instructor.ts` — `expertise` becomes an array
  of strings; `bio` becomes Portable Text (array of `block` members); add
  `alt` to `photo` image fields; fix the preview to render the first
  expertise item.
- `sanity/schemaTypes/documents/course.ts` — add `alt` to `coverImage` image
  fields.
- `sanity/schemaTypes/objects/learning-outcome.ts` — add `gauge`,
  `sparkles`, `workflow` to `iconOptions` (keep the rest; icons are rendered
  by the frontend and must be selectable).
- `sanity/lib/queries/lesson.ts` — project `"thumbnail": thumbnail` instead
  of `poster`.
- `sanity/lib/queries/course.ts` — project `"thumbnail": thumbnail` in the
  module lesson list instead of `poster`.
- `sanity.types.ts` — regenerated by `npm run typegen` (schema.json too).
